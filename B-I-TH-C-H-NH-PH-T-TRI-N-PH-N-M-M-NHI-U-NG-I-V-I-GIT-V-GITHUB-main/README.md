# Django Blog Application

Ứng dụng Blog cá nhân được xây dựng bằng **Django 4.2** và triển khai tự động trên **Render** sử dụng cơ sở dữ liệu **PostgreSQL**.

## 🚀 Demo Trực Tuyến
- **Website:** [https://my-django-blog-sjr6.onrender.com](https://my-django-blog-sjr6.onrender.com)
- **Admin Interface:** [https://my-django-blog-sjr6.onrender.com/admin](https://my-django-blog-sjr6.onrender.com/admin)

## 🛠️ Công Nghệ Sử Dụng
- **Backend:** Python 3.10.12, Django 4.2
- **Database:** PostgreSQL (Render)
- **Static Files:** WhiteNoise
- **Testing:** Django TestCase (12/12 Automated Tests Passed)
- **Deployment:** Render Web Services
